# v0.9.0 — Startup and network stability

This release addresses the confirmed network timer exhaustion that could send C64 back to Master, extends C64 startup watchdog coverage, and corrects display DMA recovery ordering. BBC Master 128, BBC Model B, Commodore 64 PAL and ZX Spectrum 48K remain together in one firmware, with the touchscreen, SD menus, keyboard, Nimbus and D81/SID optimisations retained.

- The network timer pool now covers overlapping mDNS requests and replies, preventing the reproduced empty-pool assertion. C64 terminal-caller capture remains enabled to help identify any future failure.
- C64's watchdog now starts at entry to `main`, covering USB, board, PSRAM and emulator-memory setup. A startup stall can trigger the existing recovery to Master instead of leaving a blank screen indefinitely.
- Display recovery disables linked DMA channels before aborting them, restores their state and restarts at a known frame boundary. Normal display and emulator pacing paths are unchanged.
- The four-machine build script is now executable in fresh checkouts, and the release build instructions and CI use the tested caller-capture setting.

## Hardware results

C64 physical resets from Elite and Monkey Island D81 returned to Elite with web access restored and no fallback to Master. The user subsequently reported numerous further successful physical C64 resets and reboots; counts and durations were not recorded. Settled Monkey Island ran at approximately 50.00 fps for 134.741 seconds with no additional audio underruns in that interval. Spectrum, BBC Model B and Master passed startup, display, menu resume, sound and web responsiveness checks.

These passing trials do not establish that every intermittent reset failure is eliminated. Watchdog protection begins at `main`; earlier boot failures remain outside its coverage. Bluetooth reconnection was not newly tested in this sequence; the prior features and v0.8.0 verification remain recorded separately.

## Clean build and software checks

A fresh GitHub checkout at `9f07f635` built the launcher and all four machines with GNU Arm 14.2.rel1 and Pico SDK 2.2.0, using the tested performance options and `C64_ABORT_DIAG=ON`. C64 and Spectrum dependencies and their Elite images were fetched during preparation. The existing SDK and compiler were reused; the firmware build directory was new.

Ten host regression suites passed, covering network timer exhaustion, early startup watchdogs, display DMA restart ordering, launcher recovery, terminal-caller capture, the startup banner, menu pause/resume and LED updates. These checks supplement the physical tests; the clean rebuild has not been flashed. Its generated image IDs and build label differ from the hardware-tested download.

## Install

Download **rp2350-8-bit-retro-presto.uf2**. Hold BOOT, tap RESET, release BOOT, and copy the UF2 to the USB drive. Power cycle. Tap the screen for keyboard entry or press BOOT for SD titles. Existing Wi-Fi credentials and normal save-disc contents are retained.

Local touchscreen and SD operation require no Wi-Fi setup. **Bluetooth currently requires Wi-Fi credentials saved once to initialise the radio**, although the network may subsequently be unavailable. Follow the [USB Wi-Fi guide](https://github.com/andriodious/rp2350-8-bit-retro/blob/v0.9.0/docs/presto/wifi.md). For optional web controls, open **http://8bitretro.local/** or the startup IP address and refresh any existing browser tab.

See the [touchscreen guide](https://github.com/andriodious/rp2350-8-bit-retro/blob/v0.9.0/docs/touchscreen.md) and [Bluetooth keyboard guide](https://github.com/andriodious/rp2350-8-bit-retro/blob/v0.9.0/docs/bluetooth-keyboard.md). Wake sleeping keyboards before reconnecting.

## Compatibility

Classic HID keyboards only; BLE-only keyboards are not supported. Original Nimbus is supported, not Nimbus+. Spectrum is 48K only and not every TZX encoding is supported. Heavy D81 scene loading can still interrupt audio. Choose N at the supplied C64 Elite fastloader prompt and enable joystick mode in the game before using Fire. Rolling back to older settings formats can require re-pairing devices.

v0.8.0, its firmware and all earlier checkpoints remain available unchanged. No plugin or replacement save-disc payload is included. SHA256SUMS covers the firmware, source archive and manifest. Commercial ROMs and Elite images are downloaded during build preparation; the licensed OpenSE ROM and synthetic test media remain in the source tree.
