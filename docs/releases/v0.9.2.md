# v0.9.2 — Wi-Fi-first Bluetooth startup and SD paging

BBC Master, BBC Micro, Commodore 64 and ZX Spectrum remain together in one firmware.

- With saved Wi-Fi credentials, keyboard and Nimbus wait for DHCP or the full 30-second timeout. Early NETWORK NOT FOUND no longer starts Bluetooth prematurely. Paired devices show WAITING FOR WIFI during the wait.
- With no saved Wi-Fi credentials, Bluetooth starts immediately. Local touch, keyboard, joystick and SD operation do not require network setup.
- SD titles now have PG-UP and PG-DOWN buttons, moving five titles at a time. Keyboard/Nimbus Left/Right page; Up/Down still select individual titles. Touch a title, or use BOOT, Return or A/Fire to load it.
- Retains the C64 audio-clock, quad-flash-read restoration, timer-pool, startup watchdog and display DMA fixes, with the existing performance options and diagnostics.

## Verification

The user confirmed the Wi-Fi startup test build works exactly as expected after the requested four-machine reconnection tests. No individual status samples were supplied. The preceding paging checkpoint passed all four machines, first/last pages, touch, keyboard, Nimbus, sound and menu resume.

Bluetooth host tests, DHCP/full-timeout/no-credentials startup tests, network timer/diagnostic/poll tests and combined firmware layout checks passed. C64 static headroom is 26,808 bytes. All four payloads were built; this release publishes the exact accepted UF2, not a new rebuild. Source and documentation are recorded separately; future rebuilds are not automatically hardware verified.

## Install

[Download firmware](https://github.com/andriodious/rp2350-8-bit-retro/releases/download/v0.9.2/rp2350-8-bit-retro-presto.uf2). Hold BOOT, tap RESET, release BOOT, copy the UF2 to the USB drive and power cycle. Existing Wi-Fi settings and normal save-disc contents are retained. Tap the display for keyboard input or press BOOT for SD titles.

Wi-Fi is optional. For web control, follow the [Wi-Fi setup guide](https://github.com/andriodious/rp2350-8-bit-retro/blob/v0.9.2/docs/presto/wifi.md), then open http://8bitretro.local/ or the startup IP address. See the [touchscreen guide](https://github.com/andriodious/rp2350-8-bit-retro/blob/v0.9.2/docs/touchscreen.md) and [Bluetooth keyboard guide](https://github.com/andriodious/rp2350-8-bit-retro/blob/v0.9.2/docs/bluetooth-keyboard.md).
