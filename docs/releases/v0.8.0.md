# v0.8.0 — Standalone touchscreen control

Presto can now be operated independently of the web interface, using its touchscreen, a Classic Bluetooth keyboard or a Nimbus controller. BBC Master 128, BBC Model B, Commodore 64 PAL and ZX Spectrum 48K remain together in one firmware.

- Touch the emulator to open a machine keyboard, with Shift, additional keys, Reset and Settings. Selecting a key resumes emulation and sends the keypress.
- BOOT opens SD Titles. Tap a file to boot it, or use Up/Down and BOOT. Keyboard and Nimbus selection continue to work.
- Configuration provides machine buttons, sound and LED toggles, volume and brightness sliders. LED settings apply immediately; the selected machine is remembered across power cycles.
- System Status provides dedicated joystick and keyboard setup screens, including discovery, pairing, reconnection, forgetting devices and per-machine mappings. Diagnostics remain web-only.
- Menus pause emulation and mute sound. Master resumes at normal speed without catching up paused time. Startup banners and BBC touch/BOOT entry are restored.
- Keyboard and Nimbus can reconnect when configured Wi-Fi is unavailable: an explicit connection failure or 30-second address timeout releases the shared Bluetooth startup wait.
- Existing Spectrum 50 fps work, C64 D81 optimisations, web controls, saved settings and input mappings are retained.

The README includes Master examples of touchscreen key entry, game selection, configuration and status beneath the web keyboard images. See the [touchscreen guide](https://github.com/andriodious/rp2350-8-bit-retro/blob/v0.8.0/docs/touchscreen.md).

## Install

Download **rp2350-8-bit-retro-presto.uf2**. Hold BOOT, tap RESET, release BOOT, and copy the UF2 to the USB drive. Power cycle. Tap the screen for keyboard entry or press BOOT for SD titles. Existing Wi-Fi credentials and normal save-disc contents are retained.

Local touchscreen and SD operation require no Wi-Fi setup. **Bluetooth currently requires Wi-Fi credentials saved once to initialise the radio**, although the network may subsequently be unavailable. Follow the [USB Wi-Fi guide](https://github.com/andriodious/rp2350-8-bit-retro/blob/v0.8.0/docs/presto/wifi.md). For optional web controls, open **http://8bitretro.local/** or the startup IP address and refresh any existing browser tab.

See the [Bluetooth keyboard guide](https://github.com/andriodious/rp2350-8-bit-retro/blob/v0.8.0/docs/bluetooth-keyboard.md) for pairing and mappings. Wake sleeping keyboards before reconnecting.

## Compatibility

Classic HID keyboards only; BLE-only keyboards are not supported. Original Nimbus is tested, not Nimbus+. Spectrum is 48K only and not every TZX encoding is supported. Heavy D81 scene loading can still interrupt audio. Choose N at the supplied C64 Elite fastloader prompt and enable joystick mode in the game before using Fire.

Previous releases and checkpoints remain available, including v0.7.0. No plugin or replacement save-disc payload is included. SHA256SUMS covers the firmware, source archive and manifest. Commercial ROMs and Elite images are downloaded during build preparation; the licensed OpenSE ROM and synthetic test media remain in the source tree.
