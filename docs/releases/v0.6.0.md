# v0.6.0 — Bluetooth keyboards across all four machines

BBC Master 128, BBC Model B, Commodore 64 PAL and ZX Spectrum 48K in one Presto firmware.

- Classic Bluetooth HID keyboard support alongside the original Nimbus, with scanning, Stop scan, remembered pairing and automatic reconnection.
- Up to 32 custom keyboard mappings per machine: Add mapping, press a Bluetooth key, then click its destination on the emulator keyboard. Delete mapping restores default behaviour.
- Matching keyboard/controller connection panes and keyboard status on startup/BOOT screens.
- C64 web function-key pressed highlighting.
- Existing Spectrum 50 fps improvements, D81 optimisations, Wi-Fi/Nimbus fixes and paused BOOT SD chooser retained.

## Install and use

Download **rp2350-8-bit-retro-presto.uf2**. Hold BOOT, tap RESET, release BOOT, then copy the UF2 to the USB drive. Power cycle and refresh the browser. Open **http://8bitretro.local/** or the IP shown on the screen. Select your machine and load media using SD or web upload.

For first-time networking, follow the [Wi-Fi guide](https://github.com/andriodious/rp2350-8-bit-retro/blob/v0.6.0/docs/presto/wifi.md). Existing Wi-Fi settings and normal save-disc contents are retained.

Disconnect the keyboard from other hosts and put it into pairing mode. In **Bluetooth keyboard**, Scan for keyboards, choose the device, then Connect. Follow any displayed PIN instructions. Keyboard and Nimbus reconnect independently; wake a sleeping keyboard before expecting input. See the [keyboard guide](https://github.com/andriodious/rp2350-8-bit-retro/blob/v0.6.0/docs/bluetooth-keyboard.md) for mapping and reconnection details.

## Compatibility

Classic HID keyboards only; BLE-only keyboards are not supported. Original Nimbus is tested, not Nimbus+. Spectrum is 48K only and not all TZX encodings are supported. D81 scene loading can still interrupt audio. Choose N at the supplied C64 Elite fastloader prompt, and enable its joystick mode before using Fire.

Settings v2 imports older settings, but older firmware may not read v2 records: rollback may require re-pairing and restoring preferences. Previous releases, checkpoints and exact test artifacts are preserved. No plugin or replacement save-disc payload is included. SHA256SUMS covers firmware, source archive and manifest. ROMs and game images are downloaded during build preparation rather than stored in Git.
