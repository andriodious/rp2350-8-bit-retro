# v0.7.0 — BOOT file and machine selection

BBC Master 128, BBC Model B, Commodore 64 PAL and ZX Spectrum 48K in one Presto firmware.

- Browse SD titles with a Classic Bluetooth keyboard: Up/Down and Return (or keypad Enter). Nimbus Up/Down and A/Fire continue to work.
- BOOT cycles through **file chooser → machine selector → status → emulator** when a connected input device and compatible SD titles are available. Otherwise BOOT toggles status directly.
- Select another machine with the same controls, or select the current machine to resume without restarting.
- Emulation pauses and audio is muted during menus. Held menu keys do not carry through into gameplay. Saved keyboard mappings do not change menu navigation.
- Existing four-machine media support, Spectrum 50 fps improvements, C64 D81 optimisations, saved settings, Wi-Fi and Nimbus support are retained.

## Install and use

Download **rp2350-8-bit-retro-presto.uf2**. Hold BOOT, tap RESET, release BOOT, and copy the UF2 to the USB drive. Power cycle and refresh the browser. Existing Wi-Fi settings and normal save-disc contents are retained.

Open **http://8bitretro.local/** or the IP shown at startup. First-time users should follow the [Wi-Fi guide](https://github.com/andriodious/rp2350-8-bit-retro/blob/v0.7.0/docs/presto/wifi.md).

Disconnect the keyboard from other hosts and enable pairing. In the web Bluetooth keyboard pane, scan, select the device and connect; follow any PIN instructions. Wake sleeping keyboards before use. Nimbus and keyboard reconnect independently after machine switches. See the [keyboard guide](https://github.com/andriodious/rp2350-8-bit-retro/blob/v0.7.0/docs/bluetooth-keyboard.md) for pairing and per-machine mappings.

## Compatibility

Classic HID keyboards only; BLE-only keyboards are not supported. Original Nimbus is tested, not Nimbus+. Spectrum is 48K only and not every TZX encoding is supported. D81 scene loading can still interrupt audio. Choose N at the supplied C64 Elite fastloader prompt and enable joystick mode in the game before using Fire.

Previous releases and checkpoints remain available. Older firmware may not read settings v2: rollback may require re-pairing and restoring preferences. No plugin or replacement save-disc payload is included. SHA256SUMS covers firmware, source archive and manifest. ROMs and Elite images are downloaded during build preparation, not stored in Git.
