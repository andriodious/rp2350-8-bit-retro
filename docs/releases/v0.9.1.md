# v0.9.1 — Preserve performance after saving settings

This patch release fixes the persistent C64 D81 slowdown and distorted sound that could follow saving settings, including a volume change in the touchscreen menu. It also improves C64 audio-clock accuracy to reduce underruns. BBC Master 128, BBC Model B, Commodore 64 PAL and ZX Spectrum 48K remain together in one firmware, with the touchscreen, Bluetooth keyboard, Nimbus and performance optimisations retained.

- Flash writes now restore the read timing, command and format that were active before the write. Saving preferences therefore preserves the fast quad-read mode instead of leaving flash in slower serial-read mode. The shared fix is built into all four machines.
- C64's DMA audio sample clock is closer to the intended rate at 250 MHz, reducing the mismatch between sample generation and playback. SID processing and the existing D81 optimisations are retained.
- The v0.9.0 network timer-pool, startup watchdog and display DMA recovery fixes remain included. C64 terminal-caller capture and the read-only runtime observer remain enabled for diagnosis.

## Verification

A fresh GitHub checkout at `481b5bf6ce9661b9a7a87664fe3a26fd57a579ca` built the launcher and all four machines with GNU Arm 14.2.rel1 and Pico SDK 2.2.0. Pinned emulator dependencies and checksum-protected Elite/1581 assets were verified. Nine host regression suites passed, including reproduction of the old flash-read downgrade and 246 corrected flash-write cases, alongside runtime, menu, audio, network and startup/display checks. Firmware layout, memory budgets and the SRAM restore ordering were checked.

The user then confirmed **“Build checks out fine”** after the requested power-cycle/startup, settings-save, menu-resume and sound checks on all four machines, plus Monkey Island D81 playback and physical resets on C64. This was a general acceptance; individual counts and fresh status measurements were not supplied. Earlier detailed performance measurements belong to the preceding candidate and are recorded separately.

The release download is this exact, subsequently hardware-verified clean build. It has not been rebuilt for publication. Release documentation and the CI recipe were updated separately. Future source rebuilds and CI artifacts are not automatically hardware verified.

## Install

Download **[rp2350-8-bit-retro-presto.uf2](https://github.com/andriodious/rp2350-8-bit-retro/releases/download/v0.9.1/rp2350-8-bit-retro-presto.uf2)**. Hold BOOT, tap RESET, release BOOT, and copy the UF2 to the USB drive. Power cycle. Tap the screen for keyboard entry or press BOOT for SD titles. Existing Wi-Fi credentials and normal save-disc contents are retained.

Local touchscreen and SD operation require no Wi-Fi setup. **Bluetooth currently requires Wi-Fi credentials saved once to initialise the radio**, although the network may subsequently be unavailable. Follow the [USB Wi-Fi guide](https://github.com/andriodious/rp2350-8-bit-retro/blob/v0.9.1/docs/presto/wifi.md). For optional web controls, open **http://8bitretro.local/** or the startup IP address and refresh any existing browser tab.

See the [touchscreen guide](https://github.com/andriodious/rp2350-8-bit-retro/blob/v0.9.1/docs/touchscreen.md) and [Bluetooth keyboard guide](https://github.com/andriodious/rp2350-8-bit-retro/blob/v0.9.1/docs/bluetooth-keyboard.md). Wake sleeping keyboards before reconnecting.

## Compatibility

Classic HID keyboards only; BLE-only keyboards are not supported. Original Nimbus is supported, not Nimbus+. Spectrum is 48K only and not every TZX encoding is supported. Heavy D81 scene loading and intentional menu pauses can still increase the audio-underrun counter; this release does not promise zero underruns. Choose N at the supplied C64 Elite fastloader prompt and enable joystick mode in the game before using Fire. Rolling back to older settings formats can require re-pairing devices. Startup watchdog coverage begins at `main`, not the earlier boot stages.

v0.9.0, its firmware and all previous checkpoints remain available unchanged. No plugin or replacement save-disc payload is included. SHA256SUMS covers the firmware, source archive and manifest. Commercial ROMs and Elite images are downloaded during build preparation; the licensed OpenSE ROM and synthetic test media remain in the source tree.
